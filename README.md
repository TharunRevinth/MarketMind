# MarketMind Terminal 📈

MarketMind is a professional-grade algorithmic trading dashboard and stock analysis suite. It combines machine learning predictions, real-time technical analysis, and sentiment-driven market intelligence into a high-performance terminal.

## Core Features

### 1. MarketMind Dashboard (Streamlit)
The primary user interface is a high-performance Streamlit dashboard featuring:
- **AI Trend Signals**: Real-time predictions using Logistic Regression models trained on historical price action.
- **Volume & Volatility Suite**: Overlays and metrics for VWAP (Volume-Weighted Average Price), OBV (On-Balance Volume money flow), ATR (Average True Range volatility & risk stop-loss), and Bollinger Bands (20-period, 2σ).
- **Multi-Timeframe Analysis**: Cross-examines macro daily trends against short-term intraday momentum (15M) to verify confluence and spot optimal entry points.
- **Trader's Intelligence**: Automated news analysis that scans for regulatory issues, earnings misses, and management instability.
- **Investor Profiling & Live Asset Check**: Dynamic risk assessment that tailors stock suggestions based on your income capacity, with instant matching alerts on selected assets.
- **Interactive Technical Terminal**: Interactive candlestick charts powered by Plotly with customizable overlays and secondary volume/money-flow subplots.
- **Manual Override**: Toggle between AI-driven signals and manual trend analysis for event-driven trading.

### 2. Algorithmic Scanner (CLI)
A multi-threaded scanning engine for batch processing stocks:
- **Fast Execution**: Uses `concurrent.futures` for high-speed analysis of dozens of tickers simultaneously.
- **Comprehensive Technical Edge**: Evaluates RSI, EMA Crossovers, VWAP bias, OBV money flow, ATR volatility, and Bollinger Band status to identify high-probability momentum shifts.

### 3. Machine Learning Pipeline
- **Automated Training**: Scripts to fetch historical data and train predictive models for major NIFTY 50 and NSE stocks.
- **Feature Engineering**: Models utilize Return patterns, Moving Averages (MA5/MA10), and RSI to predict price direction.

## Usage

### Run the Interactive Terminal (Recommended)
The main application is launched as a single-point Streamlit dashboard:
```bash
streamlit run app/dashboard.py
```

### Run the Batch Scanner (CLI)
To scan a specific set of stocks via the command line:
```bash
python3 main.py AAPL MSFT RELIANCE.NS
```

### Train ML Models
To update the predictive models with the latest market data:
```bash
python3 -m scripts.train_all
```

---

## Project Structure

- `app/dashboard.py`: The main Streamlit terminal entry point.
- `scanner.py` & `analyzer.py`: Core logic for technical indicators and batch scanning.
- `scripts/`: ML pipeline for data preparation and model training.
- `models/`: Persistent storage for trained `.pkl` models and scalers.
- `data/`: CSV databases for stock categories and risk profiles.
